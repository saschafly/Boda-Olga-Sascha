Migrar invitados a Firebase

Esta herramienta importa el CSV exportado desde Supabase a la colección rsvps de Cloud Firestore. No elimina ni modifica los datos de Supabase.

Utiliza esta herramienta una sola vez con el CSV completo. Si importas el mismo archivo más de una vez, se crearán respuestas duplicadas.
